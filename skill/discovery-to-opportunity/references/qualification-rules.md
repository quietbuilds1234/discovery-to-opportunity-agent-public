# Qualification Rules — BANT + MEDDPICC

Qualification supports coaching and AE handoff quality. It does **not** gate Opportunity creation by itself.

## Status labels

| Status | Meaning |
|---|---|
| **CONFIRMED** | Explicit in transcript, CRM, or clear rep clarification |
| **INFERRED** | Reasonable interpretation — must be labeled |
| **UNKNOWN** | Not present in reviewed evidence |
| **AT_RISK** | Weak, conflicting, or uncommitted |

## BANT — practical foundation

| Element | Look for | Coaching note |
|---|---|---|
| **Budget** | Funding source, pilot vs full purchase, $ amounts | Pilot Ops/Sales budget ≠ enterprise budget |
| **Authority** | Who can approve; who must be looped (Finance) | **Do not** assign authority from title alone |
| **Need** | Business problem, impact, Apollo use case | Absence of Need → lean “No opportunity” |
| **Timing** | Deadlines, “this quarter,” pilot next week, slips | Soft interest without timing can still be CREATE WITH GAPS |

Incomplete BANT → ask targeted questions; **do not** auto-block a legitimate Need + next step.

## MEDDPICC — deeper AE coaching

Assess each with status, evidence, source, rationale, optional follow-up (Layer B / handoff — not the default chat dump).

| Element | Guidance |
|---|---|
| **Metrics** | Baselines/targets/$ impact; directional goals without numbers → INFERRED/UNKNOWN |
| **Economic Buyer** | Approver beyond pilot; title alone insufficient |
| **Decision Criteria** | Must-haves for selection; casual preferences ≠ formal criteria |
| **Decision Process** | Steps/approvers to purchase; a next meeting ≠ full process |
| **Paper Process** | Security/legal/procurement; questionnaire progress may be INFERRED |
| **Identify Pain** | Core for CREATE credibility; missing pain → No opportunity |
| **Champion** | Internal seller with influence; “day-to-day owner” without advocacy → INFERRED/AT_RISK |
| **Competition** | Vendors or status quo when stated; never invent a bake-off |

Incomplete MEDDPICC → CREATE or CREATE WITH GAPS with coaching — **never** DO NOT CREATE solely for that reason.

## Conversational questioning

- Default: **one** high-leverage question at a time (Layer A).
- Skip allowed; don’t punish skips.
- Don’t re-ask Confirmed transcript/CRM facts.
- Prefer questions that improve Opportunity fields or AE handoff.

## Apollo ICP (working assumptions)

- B2B sellers with SDR/AE/RevOps motions
- Salesforce-centric workflows
- Pain in prospecting, contact data, enrichment, buyer ID, segmentation, pipeline

Networking / no-expansion / social-only → No opportunity identified.
